## 六、关键业务规则（联调注意）

1. **自动建账号**: 新增学生/教师时不传 `userId`/`username`/`password`，后端自动创建 t_user 记录并生成学号/工号
2. **停用同步**: 停用学生/教师 → 关联的 t_user.status 同步设为 0 → 该账号登录返回 403
3. **删除保护**: 学生有活跃选课记录时无法删除（先停用）；教师有运行中教学班时无法删除
4. **引用保护**: 停用课程检查教学班；停用院系检查专业/教师；停用专业检查学生；停用教室检查教学班
5. **成绩计算**: `finalScore = usualScore × 0.3 + examScore × 0.7`，根据 finalScore 自动计算 GPA 绩点和是否及格
6. **Token 校验**: 教师端/成绩接口使用 `TokenStore.validateOwner(authHeader, teacherId)` 校验身份一致性
7. **响应格式**: 前端 index.js 拦截器在 `res.status === 200` 时返回 `res.data`，其他状态码走 reject
